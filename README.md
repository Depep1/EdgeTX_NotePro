# NotePro — EdgeTX Text Display Widget

NotePro is a widget for [EdgeTX](https://edgetx.org/) radios that lets you display up to **6 lines of custom text** on your display. It's perfect for **checklists, flight notes, reminders**, or any information you want to keep visible while flying.

---

## Features

- Display up to **6 lines** of custom text  
- **Alignment** control (Left, Center, Right)  
- **Adjustable font size** (Small → XLarge)  
- **Customizable text color**  
- **FS Mode**: A mode that uses **Line 1 as a header**, and **Lines 2–6 in the body** with a large font for easy reading  
- Optional support for loading text from a `.txt` file in `NotePro/txtFiles/` (e.g. `sample.txt`) to display in fullscreen  
- Lightweight, fast, and easy to configure
